# OneDimensionalOptimization

Консольное приложение на C# для поиска минимума одномерной унимодальной функции двумя методами.

## Целевая функция

По умолчанию: `f(x) = 2*x² - 12*x`  
Аналитический минимум: `x = 3`, `f(x) = -18`.

## Как это работает

1. **Алгоритм Свенна** автоматически находит начальный интервал неопределённости `[a, b]`, внутри которого гарантированно лежит минимум.
2. Полученный интервал передаётся в два метода оптимизации:
   - **Метод дихотомии** — сужает интервал, сравнивая значения функции в двух точках около середины.
   - **Метод деления пополам (по производной)** — использует знак численной производной, чтобы отбросить половину интервала.
3. Для каждого метода считаются: точка минимума, значение функции, число итераций и время работы.
4. Результаты выводятся в консоль в виде сравнительной таблицы.

## Настройки

Все параметры задаются в начале метода `Main` в файле `Program.cs`:
