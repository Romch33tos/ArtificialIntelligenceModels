# ArtificialIntelligenceModels

Консольное приложение на C# с реализациями методов оптимизации: одномерная минимизация и метод Хука-Дживса.

## Одномерная оптимизация

Консольное приложение на C# для поиска минимума одномерной унимодальной функции двумя методами.

### Целевая функция

По умолчанию: `f(x) = 2*x² - 12*x`  
Аналитический минимум: `x = 3`, `f(x) = -18`.

### Как это работает

1. **Алгоритм Свенна** автоматически находит начальный интервал неопределённости `[a, b]`, внутри которого гарантированно лежит минимум.
2. Полученный интервал передаётся в два метода оптимизации:
   - **Метод дихотомии** — сужает интервал, сравнивая значения функции в двух точках около середины.
   - **Метод деления пополам (по производной)** — использует знак численной производной, чтобы отбросить половину интервала.
3. Для каждого метода считаются: точка минимума, значение функции, число итераций и время работы.
4. Результаты выводятся в консоль в виде сравнительной таблицы.

### Методы оптимизации

**Метод дихотомии.**  
Метод одномерной оптимизации, основанный на последовательном сокращении интервала неопределённости. На каждой итерации внутри текущего интервала `[a, b]` выбираются две симметричные точки `x1` и `x2` на расстоянии `δ` от середины:

```
x1 = (a + b - δ) / 2
x2 = (a + b + δ) / 2
```

Затем вычисляются значения функции `f(x1)` и `f(x2)` и сравниваются между собой:

- если `f(x1) < f(x2)`, минимум в левой части, правая граница сдвигается: `b = x2`;
- если `f(x1) > f(x2)`, минимум в правой части, левая граница сдвигается: `a = x1`;
- если значения равны, сдвигаются обе границы: `a = x1`, `b = x2`.

Процесс повторяется, пока длина интервала `(b - a)` не станет меньше заданной точности `ε`. В качестве решения берётся середина финального интервала. Метод устойчив, прост в реализации и не требует вычисления производной, однако сходится линейно — за одну итерацию интервал сокращается примерно вдвое.

**Метод деления пополам (по производной).**  
Использует знак производной целевой функции для отбрасывания половины интервала неопределённости. Производная вычисляется численно через конечные разности:

```
f'(x) ≈ (f(x + h) - f(x - h)) / (2h)
```

где `h` — малый шаг численного дифференцирования.

На каждой итерации вычисляется середина интервала `x_mid = (a + b) / 2` и значение производной в этой точке:

- если `f'(x_mid) < 0`, функция убывает, минимум правее: `a = x_mid`;
- если `f'(x_mid) > 0`, функция возрастает, минимум левее: `b = x_mid`;
- если `f'(x_mid) ≈ 0`, точка минимума найдена с требуемой точностью.

Итерации продолжаются, пока длина интервала не станет меньше `ε`. Метод сходится быстрее метода дихотомии за счёт использования информации о производной. Основной недостаток — чувствительность к выбору шага `h`: слишком большой шаг даёт грубую аппроксимацию, слишком малый — приводит к ошибкам округления.

### Настройки

Все параметры задаются в начале метода `Main` в файле `Program.cs`:

```csharp
double initialPoint = 0.0;      // стартовая точка для Свенна
double stepSize = 0.1;          // шаг для Свенна
double targetAccuracy = 1e-6;   // требуемая точность (epsilon)

Func<double, double> objectiveFunction = x => 2 * x * x - 12 * x;
```

## Метод Хука-Дживса

Консольное приложение на C# для поиска минимума функции двух переменных методом Хука-Дживса (конфигурационного поиска).

### Целевая функция

По умолчанию: `f(x1, x2) = 4*(x1 - 5)² + (x2 - 6)²`  
Аналитический минимум: `x1 = 5`, `x2 = 6`, `f(x1, x2) = 0`.

### Как это работает

1. **Исследующий поиск** выполняет пробные сдвиги по каждой координате вперёд и назад, обновляя точку при удачном шаге.
2. **Поиск по образцу** экстраполирует накопленное удачное направление с ускоряющим множителем `λ`.
3. При неудачном исследующем поиске шаги уменьшаются в `α` раз.
4. Алгоритм завершается, когда все размеры шагов `Δi` становятся меньше или равны `ε`.
5. В консоль выводятся: количество итераций, найденная точка минимума и значение функции.

### Метод Хука-Дживса

Метод Хука-Дживса — прямой метод оптимизации, не требующий вычисления производных. Сочетает две чередующиеся фазы:

- **Исследующий поиск** — покоординатный перебор пробных шагов `Δi` вперёд и назад от текущей точки. Если шаг уменьшает функцию — точка обновляется, иначе координата не меняется. Фаза локализует направление убывания.
- **Поиск по образцу** — экстраполяция вдоль удачного направления: `x_{k+1} = y_{n+1} + λ·(y_{n+1} − xk)`. Позволяет быстро продвигаться вдоль «оврагов» функции.
- **Уменьшение шагов** — если исследующий поиск неудачен, шаги делятся на `α`. Остановка — когда все `Δi ≤ ε`.

Метод сходится к локальному минимуму и чувствителен к выбору начальной точки и параметров `Δi`, `λ`, `α`.

### Настройки

Все параметры задаются в начале метода `Main` в файле `Program.cs`:

```csharp
double[] initialPoint = { 0.0, 0.0 };       // начальная точка (x0)
double[] initialStepSizes = { 1.0, 1.0 };   // начальные шаги по осям (Δ1, Δ2)
double precisionEpsilon = 0.01;             // точность останова (ε)
double accelerationMultiplier = 1.0;        // ускоряющий множитель (λ)
double stepReductionAlpha = 2.0;            // коэффициент уменьшения шага (α)
```
